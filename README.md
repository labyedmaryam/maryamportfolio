## 🎨 Customization

### Colors
The portfolio uses a custom color scheme defined in the Tailwind config:
- Primary: `#2563eb` (Blue)
- Secondary: `#1e40af` (Dark Blue)
- Accent: `#3b82f6` (Light Blue)

### Content
To customize the portfolio for your needs:

1. **Personal Information**: Update name, email, phone, and location
2. **Profile Image**: Replace the placeholder image URL
3. **Portfolio Projects**: Add your own project images and descriptions
4. **Skills & Services**: Modify the skills tags and service descriptions
5. **Social Links**: Update social media URLs

### Styling
- Modify the Tailwind config for custom colors
- Adjust the gradient backgrounds in the CSS
- Customize animations and hover effects
